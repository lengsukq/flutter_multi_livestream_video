# Flutter Realtime SDK Base

Provider-neutral orchestration for explicitly composed applications. Use
`RealtimeLite(providers: [...])` with optional `flutter_realtime_provider_*`
bundles. No built-in vendor catalog is imported by this package.

The full `flutter_realtime_sdk` package preserves the existing
`Realtime.standard()` API. See `../../doc/LIGHTWEIGHT_SDK.md` and the two
runnable applications in `../../examples/`.
