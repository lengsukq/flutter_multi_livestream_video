# flutter_realtime_screen_annotation

SDK-owned system drawing windows over a shared display. This package depends
only on Flutter and Whiteboard Core. It does not contain Demo code, capture a
second screen stream, own meeting credentials or depend on a media vendor.

See [System annotation SDK](../../doc/SYSTEM_SCREEN_ANNOTATION_SDK.md) for the
platform matrix, standalone and room APIs, backend protocol and validation record.
