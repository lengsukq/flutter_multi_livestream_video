# 前端优化与验收报告

日期：2026-10-14。审查对象为当前工作区，包括此前改版、用户补充优化和本轮修复；没有提交或推送。

## 结论

全站浅色视觉基础与主要页面布局已经落地。本轮检查中确认的窄屏、消息溢出、主题继承、隐藏控件键盘交互和背景透明叠加问题均已直接修复，并补充了针对性验证。

最终外观采用干净的珍珠白基底、白色内容卡片、通透玻璃功能层和少量 FaceTime 风格绿色操作。撤掉紫色品牌渐变及浓重背景色，保留红色危险操作。原生系统截图、真实视频背景下的玻璃表现和多端通话仍需独立验收。

## 最终视觉规范

| 层级 | 处理方式 |
| --- | --- |
| 页面背景 | `#F5F5F7` 不透明底色；边缘低强度淡桃色与薄荷色环境光 |
| 内容层 | `#FFFFFF` 稳定底色，轻分隔与柔和阴影；消息、表单、白板不叠加浓重材质 |
| 正文 | `#1D1D1F`；辅助文字 `#636366`；继承宿主字体和系统文字缩放 |
| 主操作 | `#187A3D` 单色；白字，不使用紫色渐变和强光晕 |
| 选中状态 | 淡绿 `#EAF6EE`、深绿图标、字重与语义标签共同表达 |
| 危险操作 | `#C52D42` 与文字、图标；录制和状态提示保留必要颜色 |
| 圆角 | 控件 20、卡片 28、视频舞台 32、弹层 36；导航与 Dock 为胶囊 |
| 玻璃层 | 局部模糊、半透明白色、细高光边缘；不在整个页面反复叠加模糊 |
| 辅助功能 | 高对比度或关闭玻璃时使用实色；减少动态效果时移除缩放与位移；键盘操作的控件保持可见 |

文字对白色的对比度约为：主文字 16.83:1、辅助文字 5.99:1、绿色操作白字 5.40:1、红色操作白字 5.49:1。测试分别校验正文及操作色对比度；真实视频上的覆盖文字仍需结合实际画面检查。

设计依据采用本地 Apple Design 指南：`layout.md › Adaptability` 要求布局随窗口、文字与输入环境适配；`focus-and-selection.md › Best practices` 要求焦点具有可见且可预测的呈现。Flutter 组件实现这些原则，材质实际效果由平台渲染器决定。

## 本轮直接完成的修复

- 修正背景合成：半透明渐变下增加独立、不透明基底。像素回归检查覆盖透明度和亮度，避免透出窗口底色造成灰浊。
- 修正窄屏后台：320 宽度的品牌信息与房间操作按钮不再撑出页面；四个入口均完成中英文布局检查。
- 修正直播消息区：20 条较长消息在短面板和 200% 文字下可滚动，保留查看旧消息的能力，默认从最新消息开始显示。
- 修正宿主主题继承：通用按钮、输入框、分段控件、容器和弹层读取主题配置；显式参数优先，保留原构造参数名与可读属性；按钮和输入框继承宿主字体。
- 修正隐藏控件交互：内部键盘焦点阻止自动隐藏；隐藏控件不能继续通过 Enter 触发，恢复显示不重建房间或释放订阅。
- 调整最终配色：撤掉大面积紫色及主按钮渐变；Flutter 与后台统一采用轻环境色、绿色重点操作和红色危险操作。

## 公开复用与架构

`flutter_realtime_design_ui` 只依赖 Flutter，公开颜色、排版、间距、圆角、玻璃配置、导航、输入与弹层等组件。使用方式：

```dart
import 'package:flutter_realtime_design_ui/flutter_realtime_design_ui.dart';
```

宿主通过 `RealtimeUiThemeExtension` 和 `RealtimeStyle.copyWith` 覆盖外观。显式控件参数优先于宿主默认值，高对比度与关闭玻璃优先保证不透明。已有 media UI 与 SDK UI 导入保留兼容导出；旧暗色入口为弃用的浅色兼容别名。

包已登记进 44 包清单，core、runtime 与轻量 SDK facade 没有引入 UI 依赖。当前通用包仍为 `publish_to: none`，可以通过仓库或本地路径复用，尚未发布到 pub.dev。

## 直播控制区补充优化

手机和窄窗口的右上角调整为一组玻璃胶囊内的成员入口与“显示选项”，离开按钮单独保留。视频完整显示／填满画面及清屏收进带文字的菜单，取消顶部第二行按钮。旧 `extraTopActions` 参数仍兼容，改为在显示菜单内呈现。

新增公开组件 `RealtimeLiveMediaControls`：主播和可发布成员在底部直接打开／关闭麦克风与摄像头，工具入口放在同一玻璃控制条；桌面大视频舞台也显示媒体控制条。控件复用共享操作生命周期与能力判断，保留处理中禁用和错误上报，不因进入页面自动采集，观众不显示发布开关。

新增主播操作与菜单回归测试，覆盖 320／390／550／768／1024／1440 宽度、短横屏、200% 字体与底部安全区；观众原有七种宽度测试继续通过。真实字体的本地模拟截图已生成并检查。Demo 完整测试现为 24 项通过，SDK UI 组件包 41 项通过，Demo 静态分析、架构、能力声明与格式检查通过。

此补充验证使用模拟会话，尚未操作真实摄像头、麦克风或真实直播厂商；没有重启应用与后台。

### 超窄窗口、点赞与头像回归修复

- 新增 176／200／240／280 宽度的直播布局；200% 字体下仍保留媒体开关、显示菜单和离开入口。超窄窗口将成员与主播工具收入菜单，聊天与互动区分行，避免固定最小宽度挤出窗口。
- 点赞按钮使用红色操作色；收到的红心使用独立动画，上浮、渐隐后从组件树移除，连续点赞不会留下固定图标。减少动画时仅短暂渐隐，且限制同时存在的红心数量。
- LiveKit 关闭默认自预览镜像，Agora 本地与远端画布显式关闭显示镜像；原始采集和发送方向没有修改。新增渲染参数测试验证本地和观众方向配置一致，真实跨设备视频仍需独立验收。
- 修复本地头像资料依赖后端回传的问题，以及已有管理成员阻止实时头像合并的问题。补测创建／加入、后台省略头像、本地 ID 不同、列表刷新后权限字段保留。

Demo 新增连续点赞消失与超窄窗口检查，完整测试现为 25 项通过，额外覆盖 176×250 短窗口。最终 44 包解析、分析与测试门禁无失败；成员合并最后的边界调整另行复验 Runtime。架构、格式、能力声明和 Demo 分析均通过。真实厂商验收单独记录，测试结果不等同于真实直播链路验收。
