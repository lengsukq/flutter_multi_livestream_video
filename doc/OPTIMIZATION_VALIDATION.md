## 构建与裁剪

最终代码已重新构建 Android Debug APK、iOS 真机目标 Release（无签名）、macOS Release、标准 JavaScript Web，以及两个轻量 Web Release 示例。Windows 已保留独立 CI runner，本机没有 Windows 构建结果；CI 配置完成不等于已运行远端 CI。

macOS 使用本次命令范围内的 `FLUTTER_SWIFT_PACKAGE_MANAGER=false` 和 CocoaPods。默认 SwiftPM 路径在第三方 Iris 的 FlutterMacOS 链接处失败，未修改用户的全局 Flutter 配置。标准 Web 通过不代表 Wasm 兼容。

本次产物统计：单媒体示例 99 个依赖条目、48 个文件、62,810,265 字节；媒体加独立 Chat 示例 102 个依赖条目、54 个文件、62,895,935 字节。这是未压缩发布目录大小。

两份轻量产物会由 `scripts/check_lite_artifacts.py` 检查：不存在全量 SDK 依赖、未选媒体/Chat adapter、未选供应商运行库及旧混合 Chat bundle。第一版仍包含共用 UI 和效果依赖；IVS Chat 原生桌面传输依赖保留。

## 性能证据与边界

同一设备、同一房间测试夹具比较改动前 `df8f9b1dff4532217da6ae6e9cabfd8d53d689fd` 与当前实现：初始视频构建均为 1 次；分别推进 5 次一秒计时，旧实现额外重建视频 5 次，新实现 0 次。这是组件重建计数，不是实际帧率或真实通话延迟结论。

10,000 条消息注入及重放中，缓存与 ID 索引始终受设置上限约束。尚未采集真实会话的堆内存趋势。验收记录增加 `joinElapsedMs`，供同一设备/供应商/场景的改动前后首次入房比较使用。

轻量示例与全量 Demo 的界面不同，因此其产物大小不能作为受控性能收益百分比。资源检查证明未选供应商被裁剪；不预先承诺总体大小或首次入房收益。

当前没有已启动的测试后端、预置验收房间与远端配合设备，本轮没有执行供应商真实通话。会议双端、主播加两观众、凭证刷新、断网恢复、摄像头切换、20 次进退房、30 分钟通话均为待验收。背景模糊/图片替换的远端方向、尺寸、切换及恢复状态也待验收。
