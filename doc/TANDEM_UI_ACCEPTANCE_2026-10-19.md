# Tandem UI 实施与验收记录（2026-10-19）

## 交付结果

基于原有未提交改动完成全前端浅色工作区统一。Demo 首页重新设计为固定品牌栏、60pt 桌面工具轨、房间目录与深色加入卡；手机为单列内容和底部导航。Green room、课堂白板、共享录制优先贴近三份 HTML 的分区、比例、字体和控件层次。

- 基础视觉：灰蓝背景、白色面板、琥珀主操作、深青状态与红色录制/危险操作；默认主题关闭玻璃，内容卡默认去掉阴影。
- 会议：缩略图独占主舞台下方，共享/白板保留本地画中画；课堂侧栏支持聊天、成员、教师举手队列、问答与可用的录制面板。
- 白板：可见网格、工具轨、页签与缩放；标注文字使用主题字体，共享标注工具限制在实际画面内。
- 数据边界：常规 Demo 不注入虚构课程或学生；测试预览明确标记样例。等待室没有回调时只读；准入状态由宿主更新，批量回调不会再重复派发单人请求。聊天不再按本地用户身份推断远端成员的老师角色。
- 设备与录制：麦克风/摄像头默认关闭；未指定设备显示系统默认，不触发采集。录制面板展示真实状态、时长和已请求选项；没有字幕、章节、额度或录制暂停假控件。
- SDK 归属：布局与组件留在 UI 包，Demo 使用公开 API，provider/core/runtime 依赖边界保持通过。

## 接口兼容

新增可选接口：`RealtimeWorkspaceShell.header/compactNavigation`、`RealtimeStyle.speakStrong`、`AnnotationPainter.fontFamily`、`AnnotationSurface.constrainToolbarToCanvas`。已有构造调用可继续使用；宿主仍可覆盖字体、主题、会话信息及内容插槽。

字体使用本地已存在的 Onest 与 Bricolage Grotesque，字体随设计包及单包 SDK 发布布局打包。没有下载任何额外字体、图片、图标库或工具。

## 二级页面补充优化

本轮额外审查二级入口，改动继续落在 SDK 包内，没有新增 Demo 页面实现。

| SDK 包 | 收敛范围 |
|---|---|
| design_ui | 默认不透明表面、无阴影卡片、独立接入的弹窗/面板主题、整窗滚动和宿主自定义列表高度约束 |
| sdk_ui | 更多与反应菜单、共享选择、背景特效、主播工具、设备列表、录制布局与结果、成员操作和离开确认 |
| classroom_ui | 发布与答题弹窗、课堂工具图标及琥珀按钮文字 |
| chat_ui | 成员管理、移除与关闭确认、消息长按操作 |
| media_ui / whiteboard_ui | 背景预设选中标记、Pre-Join 设备图标、颜色选择与文字标注弹窗 |

修复更多菜单随文字大小改变列数、反应标签自动换行，以及主播工具在 320 宽度和大文字下的溢出。宿主显式安装的 SDK 主题扩展保持优先；未安装时只在 SDK 弹层内部补齐默认主题，不改变宿主全局主题。原有权限、能力协商、设备选择、发布错误保留、录制轮询与下载条件继续由原逻辑决定。

新增独立 SDK 验收：`secondary_pages_test.dart` 包含 8 个入口 × 8 个窗口尺寸 × 2 个文字倍率，共 128 个布局组合，以及录制失败重试、不提前显示下载的回归；全部通过。24 张包内字体截图已加入 `gallery.html#secondary`。`modal_defaults_test.dart` 的 3 项测试验证默认主题与宿主覆盖、低高度键盘操作可达、宿主懒加载列表兼容，全部通过。


二级页面最终验证：全量 44 包离线 resolve/analyze/test 的 120 个检查步骤全部通过，记录为 `build/quality/tandem-secondary-final.txt`。首次全量回归发现共享停止按钮及课堂工具的宽字型溢出，修复后重新运行全量通过；对应新增测试同时验证默认测试字体和包内实际字体。Demo 分析无问题、29 项测试通过；架构、格式、能力矩阵及单包组装 12 项回归均通过。完整结果位于 `build/quality/tandem-secondary-*`。本轮没有提交、推送或进行真实厂商与真机验收。
