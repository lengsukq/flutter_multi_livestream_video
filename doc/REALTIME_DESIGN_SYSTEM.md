# Realtime 前端视觉系统

本项目统一采用单一浅色外观：不透明珍珠白基底、黑灰文字、少量 FaceTime 风格绿色操作、大圆角内容表面和浮动玻璃功能层。背景环境色只在边缘轻微出现，内容卡片保持白色；不使用紫色品牌渐变。视频底色与视频覆盖控件可使用局部深色，它们不构成应用暗色模式。Demo 不再读取外观偏好，不提供外观切换。

## 接入与边界

通用包为 `flutter_realtime_design_ui`，只依赖 Flutter。主题、颜色、几何和通用组件通过 `flutter_realtime_design_ui.dart` 公开提供，原 media_ui 与 sdk_ui 入口保留兼容导出。宿主使用 `RealtimeUiTheme.light()`；自定义配置使用 `RealtimeUiThemeExtension` 与 `RealtimeStyle.copyWith`，详见包内 README 和独立示例。

所有 UI 包可以依赖该通用包；core、runtime 和 SDK facade 不依赖 UI。房间、权限、设备采集、聊天和控制面行为继续由原有 SDK 契约承载。白板绘图颜色与媒体内容不属于界面主题色。

## 页面覆盖与导航

Flutter 顶层入口为首页、聊天、设置。创建与加入进入 Prejoin；Prejoin 默认关闭麦克风和摄像头。会议采用视频舞台、缩略图、互动侧栏和 Dock；手机将次要操作收进更多菜单。直播保留清屏、完整显示/填满、主播工具、聊天和观众入口。聊天、课堂、白板、设备、身份、服务器与录制弹层使用共同的视觉基础。

后台为概览、房间、服务、事件；房间保留媒体与独立聊天两类，服务保留两条独立厂商轴和能力矩阵。动态房间行在手机上呈现为带字段标签的卡片。后台使用系统字体，不加载远程字体。

## 验收边界

质量门禁、单测、布局检查、测试数据截图、浏览器验证和真实厂商调用分别记录。测试数据和组件截图不代表真实音视频、多设备、原生平台或云资源清理完成。检查至少覆盖 320、390、768、1024、1280、1440 宽度、短窗口、中英文与 200% 文字缩放。应用或服务不因视觉迁移自动部署、重启或发布。

## 实施细节与回归检查（2026-10-14）

- 首页、聊天入口、身份与后端配置、加入/创建、Pre-Join、会议、直播共用浅色样式。原有应用级深色偏好与切换入口已取消；兼容暗色主题入口只委托浅色主题，不创建第二套品牌色。
- 房间卡片使用中性色按钮与图标；小宽度或大字号时由横排切换为上下排。独立聊天身份卡片与后端状态卡片也使用自适应排版，不再依赖强行裁切文字解决溢出。
- 交互式胶囊、直播礼物/点赞及观众入口提供不少于 48 逻辑像素的触控高度；被动状态徽标仍保持紧凑。直播手机端的工具条在剩余宽度不足时允许横向滚动，观众与主播信息可分行显示。礼物操作调用礼物 SDK 控件，不误打开聊天面板。
- Pre-Join 的无摄像头/观众提示在短视频画布和大字体下可以单独滚动；加入操作保持在页面安全区。会议移动端次要操作使用更多菜单，成员列表和聊天继续由 SDK controller 提供状态。
- 设计系统包 `flutter_realtime_design_ui` 独立依赖 Flutter；外部宿主可以设置主题 extension，自定义颜色、圆角、玻璃、动效。预设组件不隐式创建 RTC、IM 或后台会话。

### 多人会议沉浸式布局（参考 2026-10-14 截图）

#### 摄像头纵横比 / 关闭视频占位（2026-10-14）

- **禁止非等比拉伸**：之前会议摄像头统一使用 `rendererManagesFit: true`，对直接铺满 Flutter 目标矩形的某些平台视图/原生 Texture 会将横屏画面拉成竖屏。现在由 `MediaTrackRenderer.handlesVideoFit(track)` 显式声明适配器是否能够根据**实际解码帧**自行等比 contain/cover；只有明确实现的 Agora 原生、LiveKit、ARTC、TRTC、Provider Web 等进入直接渲染路径。Chime、IVS、未经声明的第三方渲染器及原生处理纹理使用 SDK 外层 `FittedBox` 保持轨道宽高比。
- **contain / cover**：`contain` 完整展示画面，可以留空；`cover` 按原比例放大裁剪，绝不拉伸。横竖屏窗口及多人会议、直播复用同一 SDK 策略；屏幕共享继续使用原有完整展示逻辑。原始视频方向和轨道尺寸更新错误仍需实际设备/供应商验证。
- **关闭视频**：浅色直播舞台改用 `surfaceSubtle` 占位底色与成员头像，不再在没有摄像头视频时绘制突兀的黑色底框；深色宿主保留柔和暗色底板。
- **测试**：`media_camera_aspect_ratio_test.dart` 覆盖竖屏窗口横屏视频的 contain/cover、解码帧方向与轨道元数据不一致、屏幕共享兼容。

#### 直播礼物体验

- Demo Server 演示礼物是免费互动事件，不涉及实际扣费；保留事件 ID 幂等性与防刷控制，将演示组合连送调整为 **10 秒最多 20 次请求**。收到 HTTP 429 后礼物面板临时禁用再次发送约 10 秒，并提供可读提示而非直接展示异常堆栈。
- SDK `LiveInteractionSession` 仍以 Demo Server 快照作为权威状态，接收端通过消息修订提示与兜底轮询获取增量。桌面直播、移动直播及 Demo 清屏模式现在都显示 `RealtimeLiveGiftBanner`，因此即使未打开礼物面板，主播和观众也可看到别人送出的礼物横幅。前端测试覆盖冷却，Live Core 测试覆盖两个独立会话收到事件且不会重复播放。

#### 首页状态对齐及课堂跨端互动回归

- Demo 的「默认：LiveKit」与独立 Chat 的「Chat 在线」是**状态**而非操作主体。宽屏把芯片放在资料/设置卡片最右侧，窄屏及大字号时允许移至下一行但仍右对齐；不要对只有一枚芯片的行使用 `Flexible(child: status)` 导致它停在半幅空白槽的左端。主页验收测试测量状态文字与卡片右缘的实际距离。
- SDK `ClassroomSession` 从服务端**权威快照**推导举手/取消、老师发言授权/收回、Q&A 提问/回答/解决、通知、作业、资料、互动测验、课堂倒计时以及反馈。Demo 在会议网格、演讲者聚焦、共享屏幕三种舞台均放置非阻断 `RealtimeClassroomEventOverlay`；老师和学生应各自看到与其相关的操作，而不要求先打开侧边栏。
- 同一刷新批次的多条公告/作业/资料/新互动不再被“只取最后一条”吞掉：`ClassroomNotification.itemId` 将每条新增内容关联到正确的通知气泡。投票/测验收到新的回答时，老师可见响应人数，学生可见自己答题确认；老师结束互动，参与者收到“互动已结束”的非阻断提示。旧通知字段保持可选，通知来自快照而非未经验证的 IM 消息。
- 单元测试使用老师与学生两个独立 `ClassroomSession` 验证事件跨端流转及去重，组件测试检查多条通知与互动结束在接收端可见。**边界**：演示服务器目前不提供逐事件持久化日志；当多个互相抵消的瞬时操作（例如举手又立刻放下）在接收端两次权威快照之间完成，即使修订提示及时，快照 diff 也无法恢复已消失的中间状态。要做到逐事件保证送达，仍需要服务端按房间保存可重放的事件游标或独立可靠推送队列；本次没有改动会议授权协议或伪造客户端通知。

#### 竖屏摄像头在横屏舞台的纵向留白修复

会议摄像头采用 `MediaParticipantTile → MediaTrackView`：仅当渲染器明确声明 `handlesVideoFit(track)` 时直接使用完整舞台尺寸，由该渲染器基于**实际解码帧**等比 `contain/cover`；没有这一能力的原生 Texture/PlatformView 由 SDK 的外层 `FittedBox` 维护轨道比例，避免窄窗口里把人物横向拉伸。解码帧方向与初始轨道宽高可能不一致，仍需在真实供应商设备上验证。

屏幕共享继续使用 `MediaTrackView` 默认的轨道尺寸和 `BoxFit.contain`，不改变共享内容的完整显示与标注坐标；未接入具体厂商的 Widget 测试验证“上报横屏尺寸、实际竖屏视频”可占满可用高度，并单独断言屏幕共享仍使用外层 `FittedBox`。真实 Agora/LiveKit/Chime/TRTC 等设备画面及转屏时的尺寸更新需由人工联调确认。

- **多人默认主画面＋缩略图**：会议成员大于一人时，使用 SDK 公共 `RealtimeMeetingFilmstripStage` 显示主视频和底部横向可滚动成员缩略图；单人仍沿用视频布局。横向大屏中缩略图浮在主画面下部，窄屏、短窗口分配单独的缩略图区域，避免挡住主画面。
- **点击切换主画面**：点击缩略图将对应成员固定为主画面；固定成员离会时回退到当前发言人或可用视频成员。未手动固定前优先聚焦发言人，不依赖某一具体 RTC 厂商或业务角色。保留原有切换网格布局的入口。
- **控制区自动显隐**：公共 `RealtimeIdleControls` 在宽屏会议中同时承载顶部悬浮操作和底部 Dock，画面内的布局切换按钮也共用其显隐状态；默认鼠标/指针/键盘连续 4 秒无操作后渐隐，移动鼠标、滚动、点击或按键后恢复。隐藏控件不接收点击，视频和缩略图继续交互；侧边聊天、成员、举手等控制器不因隐藏被释放。
- **顶栏与右侧面板互不覆盖（2026-10-14）**：宽屏会议将 `RealtimeIdleControls` 严格限制在**左侧视频舞台**内部；右侧 330pt 的聊天/成员/课堂面板是外层 `Row` 中的兄弟节点，不再位于顶栏 `Stack` 后面。顶栏使用 `dense` 单行模式，保留房间号/录制状态/必要按钮，隐藏冗长且重复的参与者 UUID 和装饰徽标。网格视频不再永久为悬浮顶栏预留顶部大空白；通知层仍避开可见控件。侧栏打开时将次要 Dock 动作收纳到「更多」，避免实际舞台变窄后水平滚动隐藏菜单。布局测试覆盖 1024/1280px 宽屏的顶栏与面板空间隔离、侧栏关闭命中、无布局异常。
- **布局切换按钮遮挡修复**：桌面端「网格布局/聚焦布局」入口属于 `RealtimeMeetingTopBar.trailingActions`，不再放在视频区域的右上角和悬浮顶部栏重叠。仅多人、非共享时出现；顶部栏和底部 Dock 一起遵循闲置显隐。课堂通知区域另预留顶部操作高度，避免与悬浮栏抢位置。
- **稀疏网格充分利用高度**：`RealtimeVideoGrid` 依据成员数、列数和可用舞台高度计算每行卡片高度。双人两列不再被固定 16:9 锁死在顶部留下大片空白；成员较多或窗口较短时设置最小卡片高度并继续滚动。Demo 网格保持紧凑顶部边距，只为底部 Dock 保留操作空间；顶部栏本身渐隐且不会永久压缩视频高度。
- **移动端与辅助功能**：宽度小于 600 逻辑像素时保持常显 Dock 和更多菜单，避免手势操作找不到控制；辅助导航启用时取消自动隐藏。发布 SDK 的通用组件不维护房间、媒体流或服务端状态，Demo 负责组装，不重复实现核心逻辑。
- **测试**：`packages/flutter_realtime_design_ui/test/design_ui_test.dart` 覆盖点击缩略图、闲置隐藏和指针恢复、辅助导航常显；`example/test/demo_composable_meeting_test.dart` 覆盖三人假会话、聚焦与点击切换和原有宽度矩阵。实际画质、视频层级/纹理、鼠标交互细节及音视频供应商联调仍需真实设备验收。
